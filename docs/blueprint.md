# **App Name**: EpubMentor

## Core Features:

- User Accounts: User authentication and authorization.
- Book Library: Dashboard to view uploaded books.
- Epub Parsing and Upload: Upload and parse .epub files, convert to structured line-based content (title, subtitle, content, blank).
- Book Reader: Mobile-responsive book reader displaying paginated content based on screen size.
- Display Page Info: Display page number relative to number of total pages
- AI Question Answering: Question box to query Gemini AI tool to answer user questions about the book and current page.
- AI Content Analysis: Give Gemini the book's name, current page, and line content of the current page. Gemini analyzes all that with user query and responds to user in markdown

## Style Guidelines:

- Primary color: Dark blue (#3F51B5) to convey trustworthiness and focus.
- Background color: Very light blue (#F0F2FA), nearly white, to ensure comfortable reading.
- Accent color: Vibrant orange (#FF9800) to highlight interactive elements.
- Body font: 'Inter', a sans-serif, providing a clean and modern reading experience for long texts.
- Headline font: 'Space Grotesk', a sans-serif. Pairs well with 'Inter'. Use for headers, buttons and other short text runs
- Simple, clear icons for navigation and key functions (upload, search, settings).
- Clean and intuitive layout optimized for mobile and desktop reading.
- Subtle transitions for page turns and interactive elements, enhancing the user experience without being distracting.
